# Домашнее задание к работе 7
## Условие задачи
Написать программу, которая для заданной стоимости покупки в
копейках выводить текстовое сообщение, отображающие значение в рублях и
копейках с правильным склонением слова «копейка».
**Вариант 13**

##Алгоритм

**Начало**
-Ввести целое число n: стоимость покупки в копейках.
-Вычислить рубли: r = n / 100 (целая часть от деления).
-Вычислить копейки: k = n % 100 (остаток от деления).
-Вычислить последнюю цифру копеек: d = k % 10.
-Вывести r и k.
-Если 11 ≤ k ≤ 14, вывести слово «копеек».
-Иначе проверить d:
-если d = 1, вывести «копейка»;
-если d = 2, 3 или 4, вывести «копейки»;
-во всех остальных случаях вывести «копеек».
**Конец**

### Блок-схема

## Код

```c
#define _CRT_SECURE_NO_WARNINGS
#include <stdio.h>
#include <locale.h>

int main()
{
    int n, r, k, d;
    setlocale(LC_ALL, ".UTF-8");
    printf("Введите стоимость в копейках: ");
    scanf("%d", &n);
    r = n / 100;
    k = n % 100;
    d = k % 10;
    printf("%d руб. %d ", r, k);
    if (k >= 11 && k <= 14)
        printf("копеек\n");
    else
    {
        switch (d)
        {
        case 1:
            printf("копейка\n");
            break;
        case 2:
        case 3:
        case 4:
            printf("копейки\n");
            break;
        default:
            printf("копеек\n");
        }
    }
    return 0;
}
```
